# Chapter 1 — Option Strategies and No-Arbitrage

This project implements the financial foundations studied in Chapter 1 of the quantitative finance curriculum.

## Concepts covered

- European call and put payoffs
- Long and short option positions
- Portfolio aggregation
- Continuous and discrete compounding
- Put-call parity
- Detection of static arbitrage opportunities
- Elementary option strategies
- Terminal payoff and profit analysis

## Implemented strategies

- Long call
- Long put
- Bull call spread
- Bear put spread
- Long straddle

## Project structure

- src: financial models and strategy constructors
- tests: unit tests
- notebooks: numerical analysis and visualisations
- data: future input data
- figures: generated figures

## Running the tests

From the chapter project directory:

    python -m pytest -v

## Running the notebook

Open notebooks/option_strategies_analysis.ipynb.

## Limitations

The option premiums currently used in the notebook are pedagogical inputs. They are not yet generated by a pricing model such as Black-Scholes.
